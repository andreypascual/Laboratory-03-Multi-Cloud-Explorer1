
## Checkpoint 2

### Amazon Web Services (AWS)
 
Brief Overview
Amazon Web Services (AWS) is the world’s most widely adopted cloud platform, 
offering on-demand computing resources and services to businesses, governments, and individuals worldwide. 
Launched in 2006, it provides flexible, scalable, and cost-effective cloud solutions.
 
### Global Infrastructure
 
- 32 geographic Regions worldwide
​
- 102 Availability Zones
​
- Network of edge locations and regional caches for low-latency content delivery
 
### Cloud Management Console
 
- Web-based interface to access and manage all AWS services
​
- Centralized dashboard for monitoring, security, and billing
 
### Four Core Services
 
1. Amazon EC2 — Elastic Compute Cloud (virtual servers)
​
2. Amazon S3 — Simple Storage Service (object storage)
​
3. Amazon VPC — Virtual Private Cloud (networking)
​
4. IAM — Identity and Access Management (security)
 
### Three Advantages
 
- ✅ Widest range of services and deepest functionality
​
- ✅ Largest community and marketplace support
​
- ✅ Pay-as-you-go pricing with no upfront costs
 
### Typical Enterprise Use Cases
 
- Web and mobile application hosting
​
- Big data analytics and data lakes
​
- Disaster recovery and backup
​
- Enterprise-level AI/ML development

### Microsoft Azure
Brief Overview Microsoft Azure is a cloud computing platform designed to build, deploy, and manage applications across a global network of Microsoft-managed data centers. It integrates seamlessly with existing Microsoft tools and technologies.

### Global Infrastructure
60+ Regions worldwide

Available in more geographies than any other cloud provider

### Cloud Management Console
Unified web portal to manage all Azure resources

Customizable dashboard and built-in monitoring tools

### Four Core Services
Azure Virtual Machines — Compute service

Azure Blob Storage — Scalable object storage

Azure Virtual Network — Secure networking

Azure AD — Active Directory (identity management)

### Three Advantages
✅ Best integration with Microsoft ecosystem (Windows, Office, SQL, .NET)

✅ Strong hybrid cloud capabilities

✅ Enterprise-grade security and compliance

### Typical Enterprise Use Cases
Migration of on-premises Microsoft workloads

Enterprise app development

Virtual desktop infrastructure (VDI)

Business intelligence and analytics

### Google Cloud Platform (GCP)
 
Brief Overview
Google Cloud Platform is a suite of cloud computing services 
that runs on the same infrastructure Google uses internally 
for its end-user products like Google Search and YouTube. 
It is known for strong data analytics, AI, and open-source leadership.
 
### Global Infrastructure
 
- 34 Regions worldwide

- 103 Availability Zones

- High-speed private global fiber network
 
### Cloud Management Console
 
- Clean, modern interface with project-based organization

- Centralized access to billing, monitoring, and APIs
 
### Four Core Services
 
1. Google Compute Engine — Virtual machines

2. Google Cloud Storage — Unified object storage

3. Google VPC — Virtual Private Cloud networking

4. Cloud IAM — Identity and Access Management
 
### Three Advantages
 
- ✅ Industry-leading AI/ML and data analytics tools

- ✅ Strong open-source and Kubernetes leadership

- ✅ Cost-effective and transparent pricing
 
### Typical Enterprise Use Cases
 
- Data analytics and machine learning pipelines

- Cloud-native application development

- Scalable web and mobile backends

- Multi-cloud and hybrid deployments

 AWS-It has the largest ecosystem with over 200+ fully featured services,
 covering virtually every use case from basic computing to advanced AI, IoT, and quantum computing.
 
2. Which provider best integrates with Microsoft technologies?
 
 Microsoft Azure-It is built specifically to work seamlessly 
 with Windows Server, SQL Server, .NET, Office 365, and other Microsoft tools,

 Google Cloud Platform-Google invented Kubernetes and remains its primary supporter;

  I would choose Google Cloud Platform because of its strong

## Check Point4

### Client A – Startup Company
Recommended Platform:✅Amazon Web Services (AWS)
Reason:AWS is ideal for startups because it offers a free tier and pay-as-you-go pricing, 
which fits a limited budget while allowing services to scale as the business grows. 
It also has the largest ecosystem of tools and global infrastructure to support rapid expansion. 
The startup could use Amazon EC2 for their app servers, Amazon S3 to store media and user data, and Amazon RDS for a managed database.
 
### Client B – University
Recommended Platform:✅Microsoft Azure
Reason:Azure integrates seamlessly with the university's existing Microsoft technologies like Windows Server, Microsoft 365, and Active Directory, 
making migration much easier and more cost-effective.
It provides a familiar environment for IT staff and strong compliance standards suitable for educational institutions. 
The university could use Azure Virtual Machines, Azure AD, and Azure Files for secure storage and collaboration.

### Client C – AI Research Company
Recommended Platform:✅Google Cloud Platform (GCP)
Reason:GCP is the best choice for AI and machine learning because 
it offers specialized tools built on Google's own advanced technology and strong leadership in Kubernetes. 
It provides powerful computing resources needed for training complex models efficiently.
The company could use Vertex AI for building ML models, Google Compute Engine with GPUs for high-performance computing, and Google Cloud Storage for large datasets.
 
### Client D – Global E-Commerce Company
Recommended Platform:✅Amazon Web Services (AWS)
Reason:AWS has the most extensive global infrastructure with the highest number of regions and availability zones worldwide, 
ensuring low latency and reliable access for customers everywhere. 
Its auto-scaling features handle sudden traffic spikes smoothly without downtime. 
The company could use Amazon EC2 Auto Scaling, Amazon S3 for product images and backups, and Amazon CloudFront for fast content delivery globally.
