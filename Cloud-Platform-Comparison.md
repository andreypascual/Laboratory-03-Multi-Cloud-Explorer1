1. Which cloud provider offers the broadest range of services?
 
AWS-It has the largest ecosystem with over 200+ fully featured services,
covering virtually every use case from basic computing to advanced AI, IoT, and quantum computing.
 
2. Which provider best integrates with Microsoft technologies?
 
Microsoft Azure-It is built specifically to work seamlessly 
with Windows Server, SQL Server, .NET, Office 365, and other Microsoft tools, 
making migration straightforward for Windows-based businesses.
 
3. Which provider is strongest in Artificial Intelligence and Kubernetes?
 
Google Cloud Platform-Google invented Kubernetes and remains its primary supporter; 
it also offers industry-leading AI tools like Vertex AI that were built on Google’s own technology.
 
4. Which cloud platform would you personally choose and why?
 
 I would choose Google Cloud Platform because of its strong 
focus on innovation, cost efficiency, and excellent tools for data analytics and modern application development. 
It also runs on the same reliable infrastructure used by Google’s own services.
